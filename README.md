# PERSONAL PORTFOLIO - ARCHIT SHET

## PROJECT OVERVIEW

A modern, responsive personal portfolio website showcasing projects, skills, and professional information. Built with Angular and featuring smooth animations, dark theme, and interactive UI elements.

- Forms: Formspree integration
- Deployment: Render
- Version Control: Git & GitHub
